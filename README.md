Tecnologias y Arquitectura:
Lenguaje: C# (.NET)
Arquitectura: Multicapa (UI, BLL, DAL, BE, MPP).
Base de Datos: SQL Server (Scripts incluidos).
Principios: Uso de principios SOLID y Patrones de diseño para asegurar escalabilidad y mantenimiento.

Control de seguridad mediante hashing de contraseñas.
Generacion de informes y persistencia de datos relacionales.
